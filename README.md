# Sistema de Gestão Acadêmica — Tela de Login

## Arquivos
- `index.html`: estrutura e campos da tela.
- `style.css`: cores, layout, responsividade e estilos.
- `script.js`: mostrar/ocultar senha e validação básica.

## Como executar
1. Extraia o ZIP para uma pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador. Você também pode usar a extensão Live Server.

## Importante
Esta é uma demonstração de interface. O JavaScript valida os campos no navegador, mas não autentica usuários de verdade. Para isso, será necessário um backend, armazenamento seguro de senhas e integração com o sistema de usuários. Não coloque senhas reais em código JavaScript no navegador.

A foto e a fonte são carregadas de serviços externos e precisam de conexão com a internet.
